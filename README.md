nano README.md# DevOps Task Tracker

A simple single-page task management application created as a deployment
practice project.

## Technologies Used

- HTML
- CSS
- JavaScript
- Git and GitHub
- Vercel
- WSL Ubuntu

## Features

- Add tasks
- Delete tasks
- Simple and responsive UI

## Installation Steps

1. Open Ubuntu using WSL.
2. Create a project directory.
3. Create HTML, CSS and JavaScript files.
4. Develop the application.
5. Initialize Git.
6. Push the project to GitHub.
7. Import the GitHub repository into Vercel.
8. Deploy the project.
